# Hydration Reminder App 💧

## Lab Session

In this lab session, we created a Hydration Reminder app using React Native and Expo.

The app reminds users to drink water by sending notifications at a selected time interval.

### Features

- Request permission to send notifications.
- Enter a custom reminder message.
- Set the reminder interval in minutes.
- Start repeating water reminders.
- Stop scheduled reminders.
- Display the current reminder status (Active or Inactive).

### Technologies Used

- React Native
- Expo
- TypeScript
- Expo Notifications

### What We Learned

- Using `useState` and `useEffect`.
- Working with TextInput and Button components.
- Requesting notification permissions.
- Scheduling and cancelling notifications.
- Handling user inputs and button clicks.
